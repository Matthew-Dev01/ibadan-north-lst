# Ibadan North LST Project : Matthew Afolabi

**Cohort:** Geospatial Developer Lab Africa Cohort One : Week 1

This repository is my portfolio for the first task by Geospatial Developer Lab Africa Cohort. It tracks the development of a project investigating **Land Surface Temperature (LST) dynamics in Ibadan North Local Government Area, Oyo State, Nigeria**, and how they relate to land use/land cover change.

Full project brief: see [PROJECT_BRIEF.md](./PROJECT_BRIEF.md) contains the spatial question, study area, required datasets with source links, and planned approach.

- Week 1: Defined spatial question, identified required datasets, set up repository structure.
